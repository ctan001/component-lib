# speaker-8002b — 8002B功放喇叭模块

**類別**：actuator
**介面**：PWM
**工作電壓**：3.3–5.0 V
**邏輯**：pwm

## 描述

8002B 功放喇叭，小音頻信號放大約 8.5 倍，PWM 輸出不同頻率音調

## 接腳定義

| 接腳 | 功能 | 方向 |
|:--|:--|:--|
| VCC | 電源 3.3V/5V | input |
| GND | 接地 | input |
| IN | 音頻輸入（PWM 信號） | input |
