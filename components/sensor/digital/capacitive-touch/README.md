# capacitive-touch — 电容触摸传感器

**類別**：sensor/digital
**介面**：GPIO
**工作電壓**：3.3–5.0 V
**邏輯**：active-high

## 描述

電容觸摸感應模組，觸摸時 S=HIGH，未觸摸 S=LOW

## 接腳定義

| 接腳 | 功能 | 方向 |
|:--|:--|:--|
| VCC | 電源 3.3V/5V | input |
| GND | 接地 | input |
| S | 信號端 | output |

## MicroPython Driver

```python
# driver 路徑：drivers/micropython/capacitive_touch.py
```

請將 `capacitive_touch.py` 複製到 Pico，再執行 `example.py`。
