# uv — 太阳光紫外线传感器

**類別**：sensor/analog
**介面**：ADC
**工作電壓**：3.3–5.0 V
**邏輯**：analog

## 描述

UV 紫外線感應，輸出電流正比光照強度，模組電路已轉為電壓類比輸出

## 接腳定義

| 接腳 | 功能 | 方向 |
|:--|:--|:--|
| VCC | 電源 3.3V/5V | input |
| GND | 接地 | input |
| S | 信號端 | output |

# driver 路徑：drivers/micropython/uv.py
