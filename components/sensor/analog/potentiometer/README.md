# potentiometer — 旋转电位器

**類別**：sensor/analog
**介面**：ADC
**工作電壓**：3.3–5.0 V
**邏輯**：analog

## 描述

旋轉電位器，輸出 0–VCC 類比電壓，對應 ADC 0–65535

## 接腳定義

| 接腳 | 功能 | 方向 |
|:--|:--|:--|
| VCC | 電源 3.3V/5V | input |
| GND | 接地 | input |
| S | 信號端 | output |

## MicroPython Driver

```python
# driver 路徑：drivers/micropython/potentiometer.py
```

請將 `potentiometer.py` 複製到 Pico，再執行 `example.py`。
