# pressure-film — 薄膜压力传感器

**類別**：sensor/analog
**介面**：ADC
**工作電壓**：3.3–5.0 V
**邏輯**：analog

## 描述

薄膜壓力感應，壓力越大 ADC 值越小，類比輸出壓力強度

## 接腳定義

| 接腳 | 功能 | 方向 |
|:--|:--|:--|
| V | 電源 VCC | input |
| G | 接地 GND | input |
| S | 信號端（類比） | output |
