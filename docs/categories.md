# 元件分類定義

| 分類路徑 | 說明 |
|:--|:--|
| `sensor/digital` | 數位輸入感應器（GPIO HIGH/LOW 輸出） |
| `sensor/analog` | 類比輸入感應器（ADC 電壓輸出） |
| `sensor/dual` | 同時具備 ADC 類比和 GPIO 數位輸出 |
| `sensor/1wire` | 單線協議感應器（OneWire） |
| `sensor/humidity` | 溫濕度感應器（DHT 協議） |
| `sensor/imu` | 慣性測量單元（加速度/陀螺儀） |
| `sensor/ultrasonic` | 超聲波測距 |
| `input/` | 使用者輸入裝置（按鍵、搖桿、編碼器、IR） |
| `actuator/` | 輸出驅動裝置（蜂鳴器、馬達、伺服） |
| `display/led` | LED 發光裝置 |
| `display/7seg` | 七段數碼管 |
| `display/matrix` | 點陣顯示 |
| `display/lcd` | LCD 液晶顯示 |
| `display/oled` | OLED 有機電激發光顯示 |
| `module/rtc` | 實時時鐘 |
| `module/rfid` | RFID 讀卡器 |
